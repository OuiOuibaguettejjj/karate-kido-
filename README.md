# Karate Kido 2 — prototype de reproduction 2D

Dépôt de travail pour un prototype web 2D inspiré de Karate Kido 2.

Le gameplay, les règles, l'interface et les sensations seront étudiés puis reproduits avec des ressources originales. Les modifications du jeu seront développées sur des branches dédiées, jamais directement sur `main`.
